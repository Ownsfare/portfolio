Smart Spectacles for Visually Impaired

← Back to Projects

Objective

Develop a portable, affordable assistive device that enables visually impaired individuals to read printed text independently. The device should be lightweight, user-friendly, and provide real-time text-to-speech conversion to improve accessibility and independence for people with visual impairments.

The primary goal was to create an innovative solution that bridges accessibility gaps through technology, making printed information accessible to visually challenged individuals without requiring external assistance.

Key Milestones

Phase 1: Concept & Design

Conceived the idea and designed the hardware form factor. Researched user needs and requirements for visually impaired individuals. Designed ergonomic spectacles frame that could house the necessary components.

Phase 2: Hardware Integration

Integrated Raspberry Pi as the core processing unit. Selected and integrated camera module for image capture. Designed power management system for portable operation.

Phase 3: OCR Implementation

Implemented Tesseract OCR engine for text recognition. Developed image preprocessing algorithms to enhance OCR accuracy. Optimized for various fonts, sizes, and text orientations.

Phase 4: Text-to-Speech Integration

Integrated high-quality text-to-speech engine. Implemented audio output system with clear, natural-sounding voice. Added language support and voice customization options.

Phase 5: Testing & Refinement

Conducted user testing with visually impaired individuals. Refined user interface and interaction methods. Optimized performance and battery life for practical use.

Product Requirements Document (PRD)

Functional Requirements

  • Capture images of printed text using onboard camera
  • Process images to extract text using OCR
  • Convert recognized text to speech output
  • Support multiple languages
  • Adjustable reading speed and voice settings
  • Battery-powered portable operation
  • Simple user interface with tactile controls
  • Real-time processing with minimal latency

Non-Functional Requirements

  • Weight: Less than 200g for comfortable wear
  • Battery life: Minimum 2 hours of continuous use
  • OCR accuracy: >85% for standard printed text
  • Processing time: <3 seconds per page
  • Audio quality: Clear, natural-sounding speech
  • Durability: Robust design for daily use
  • Cost: Affordable for target users

User Stories

  • As a visually impaired user, I want to read printed documents independently so that I don't need assistance from others.
  • As a user, I need clear audio output so that I can understand the content being read.
  • As a user, I want simple controls so that I can operate the device easily without visual feedback.

System Architecture

Hardware Components

  • Raspberry Pi 4 Model B (or similar) as main processor
  • High-resolution camera module (8MP+)
  • Compact speaker system with amplifier
  • Rechargeable battery pack (5000mAh+)
  • Tactile buttons for user control
  • LED indicators for system status
  • Custom 3D-printed frame housing

Software Architecture

  • Image Capture Module: Camera interface and image acquisition
  • Image Processing Module: Preprocessing, enhancement, and optimization
  • OCR Module: Text extraction using Tesseract
  • TTS Module: Text-to-speech conversion
  • User Interface: Control system and feedback mechanisms
  • Power Management: Battery monitoring and optimization

Key Achievements

  • Successfully created a portable, wearable assistive device
  • Achieved >85% OCR accuracy for standard printed text
  • Developed user-friendly interface suitable for visually impaired users
  • Created affordable solution using open-source technologies
  • Demonstrated practical application in real-world scenarios
  • Bridged accessibility gaps through innovative technology

Challenges & Solutions

Challenge 1: OCR Accuracy

Problem: Low accuracy in recognizing text from various fonts, sizes, and lighting conditions.

Solution: Implemented comprehensive image preprocessing including noise reduction, contrast enhancement, and perspective correction. Fine-tuned Tesseract parameters for optimal performance.

Challenge 2: Portability & Power

Problem: Balancing processing power requirements with battery life and device weight.

Solution: Optimized algorithms for efficiency, implemented power management strategies, and selected appropriate hardware components for balance.

Challenge 3: User Experience

Problem: Creating an intuitive interface for users who cannot see visual feedback.

Solution: Designed tactile controls with audio feedback, implemented voice prompts, and conducted user testing with visually impaired individuals.
