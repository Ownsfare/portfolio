UAV for Autonomous Search & Rescue

← Back to Projects

Objective

Develop an autonomous Unmanned Aerial Vehicle (UAV) capable of performing search and rescue operations in challenging environments. The system was designed to compete in the AUVSI SUAS Competition (USA) and demonstrate advanced capabilities in autonomous navigation, object detection, and mission execution.

The primary goal was to create a robust, reliable UAV system that could autonomously locate and identify targets in a designated search area, navigate complex terrain, and execute precision tasks while maintaining safety and operational efficiency.

Key Milestones

Phase 1: System Architecture & Design

Designed the overall system architecture, including hardware selection, software framework, and communication protocols. Established team structure and development workflow for the 18-member software subsystem team.

Phase 2: Computer Vision Implementation

Implemented advanced computer vision algorithms using OpenCV for real-time image processing, object detection, and target recognition. Developed custom algorithms for feature extraction and pattern matching.

Phase 3: Machine Learning Integration

Integrated machine learning models for enhanced object detection and classification. Trained models on custom datasets to improve accuracy and reduce false positives in target identification.

Phase 4: Autonomous Navigation

Developed autonomous navigation system with path planning, obstacle avoidance, and GPS integration. Implemented real-time decision-making algorithms for mission execution.

Phase 5: Testing & Competition

Conducted extensive field testing and optimization. Achieved top ranking at AUVSI SUAS Competition (USA) through superior performance in autonomous flight, target detection, and mission completion.

Product Requirements Document (PRD)

Functional Requirements

  • Autonomous takeoff and landing capabilities
  • Real-time object detection and classification
  • GPS-based navigation with waypoint following
  • Obstacle detection and avoidance
  • Target identification and tracking
  • Mission planning and execution
  • Telemetry data transmission
  • Emergency landing protocols

Non-Functional Requirements

  • Flight time: Minimum 30 minutes
  • Operating range: Up to 2 km
  • Object detection accuracy: >90%
  • Navigation precision: Within 5 meters
  • Real-time processing: <100ms latency
  • Weather resistance: Operate in moderate wind conditions
  • Safety compliance: Follow AUVSI competition regulations

User Stories

  • As a mission operator, I want the UAV to autonomously navigate to search areas so that I can focus on monitoring and decision-making.
  • As a search team member, I need accurate target detection so that rescue operations can be initiated quickly.
  • As a system administrator, I require real-time telemetry so that I can monitor system health and performance.

System Architecture

Hardware Components

  • Multirotor UAV platform with high payload capacity
  • High-resolution camera with gimbal stabilization
  • GPS/GNSS receiver for precise positioning
  • IMU and barometric sensors for attitude estimation
  • Onboard computer (Raspberry Pi or similar) for processing
  • Radio communication system for telemetry

Software Architecture

  • Perception Layer: Computer vision and sensor fusion for environment understanding
  • Planning Layer: Path planning and mission execution algorithms
  • Control Layer: Flight control and stabilization systems
  • Communication Layer: Telemetry and command interface
  • Safety Layer: Emergency protocols and fail-safe mechanisms

Key Achievements

  • Implemented real-time computer vision with <100ms processing latency

  • Created scalable architecture for future enhancements
  • Demonstrated reliability in competitive environment

Challenges & Solutions

Challenge 1: Real-time Processing

Problem: Processing high-resolution images in real-time while maintaining low latency.

Solution: Implemented optimized image processing pipelines, used multi-threading, and optimized algorithms for efficient computation.

Challenge 2: Environmental Variability

Problem: Varying lighting conditions and weather affecting object detection accuracy.

Solution: Developed adaptive algorithms that adjust to environmental conditions and trained ML models on diverse datasets.

Challenge 3: Team Coordination

Problem: Managing a large 18-member team with different expertise areas.

Solution: Established clear communication protocols, modular architecture, and regular integration testing.
